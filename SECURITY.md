# Security policy

This repository currently publishes SQL conventions and reference migrations;
it does not operate a hosted database service or receive application data.

To report a vulnerability in the SQL artifacts, guidance, or validation
workflow, use GitHub's private vulnerability reporting for this repository
when available. Do not include credentials, personal data, or production
database contents in a report.

For a security issue in a consuming application, report it to that application's
maintainers. This repository does not receive or centralize consumer data.

There are no released runtime packages or supported runtime versions yet.
